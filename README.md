# STAR-release

**Distributed Three-Stage Coverage Deployment of Heterogeneous USV Swarms under Communication Constraints**

Self-contained, reproducible source package accompanying the manuscript *"Distributed Coverage Control for Heterogeneous USV Swarms with Local Geometric Optimization and Conditional Hole Recovery"* .

This package lets reviewers and interested researchers **reproduce all experiments and figures** from the paper with a few commands. All 12-seed experiment results (corrected implementation) are included.

## Reproduce the Paper's Results

### 1. Setup

```bash
# Python 3.11 recommended
python -m venv star_sci_env
source star_sci_env/bin/activate        # Windows: star_sci_env\Scripts\activate
pip install -r requirements.txt
```

### 2. Run all six experiments (12 seeds)

```bash
cd STAR-release
python experiments/run_suites.py
```

This writes `results/suite/all_runs.csv` with the same 504-row, six-suite structure as the shipped file. **Note:** a full 12-seed run takes several hours; the precomputed results are already included in `results/`. For a quick smoke check, use:

```bash
python experiments/run_v4_experiments.py --suite smoke --out results/repro
```

To reproduce the shipped results without re-running, verify:

```bash
python -c "
import pandas as pd
df = pd.read_csv('results/suite/all_runs.csv')
print('rows:', len(df))          # expect 504
print(df[(df.suite=='benchmark') & (df.N==40)].groupby('method')['final_coverage'].mean())
"
```

### 3. Reproduce deployment trajectories and baseline sweeps

```bash
python experiments/run_demo_figures.py
```

This writes the trajectory archives (`convergence_*`, `snapshots_*`, `fluxtrace_*`), the baseline sweep rows, and `results/fairness_gap.json` under `results/demo_figs/`.

### 4. Reproduce statistical significance tests

```bash
python experiments/significance_test.py
```

This recomputes paired t-tests and Wilcoxon signed-rank tests for STAR vs. each baseline at N=40 and N=100 from `results/suite/all_runs.csv`, and overwrites `results/significance_tests.csv`.

### 5. Reproduce figures

```bash
python figures/make_figures_sci.py
```

This regenerates the composite panels FigR1–FigR5 (PNG + PDF) into `figures/beauty3/` from the shipped results. The full figure set embedded in the manuscript (FigR1–R5 and FigS1–S7) is shipped under `paper/figures_v2/` and is consistent with the shipped data.

### 6. Unit tests

```bash
pip install pytest
pytest tests/ -v
```

Runs the 13 mechanism unit tests (SPH fluid force balance, hole-recovery trigger timing, VEVF partition invariants) and confirms the shipped `src/` matches the equations in §3 of the manuscript.

### 7. Reproduce mechanism operating-regime experiments

These reproduce the operating-regime sweeps reported in §4.8/§4.9 and Supplementary S6 (H2/H3, F4/H4, F6, H6). All runners are non-invasive — they read `configs/*.yaml`, do not modify any algorithm, and write only under `results/mech_verify/` and `figures/mech_verify/`.

```bash
python run_step4.py --stage all     # F2 dense-cluster fluid, F3 comm-loss fluid, H2 hole regime, H3 hole f_max sweep
python run_step5.py --stage all     # F4 fluid-as-regularizer, H4 communication-isolated hole
python run_f6.py                    # F6 k_fluid sensitivity (0 / 0.5x / 1x / 2x)
python run_h6.py                    # H6 hole-fill boundary factorial (d/C_th x hole diameter)
```

For a quick smoke run of a single stage:

```bash
python run_step4.py --stage f2 --seed 42
python run_f6.py --seed 42
```

The shipped results under `results/mech_verify/` are already committed; re-running the four commands above regenerates them bit-for-bit within numerical tolerance. `run_mechanism_regression.py` is the before/after mechanism-fix auditor and is not required for manuscript reproduction.

### 8. Reproducibility self-check

```bash
python experiments/repro_check.py
```

Runs the 12-seed × 5-method benchmark episodes (N=40/100, 120 runs) and compares every row against `results/suite/all_runs.csv`; the shipped result `results/repro_check/benchmark_repro.csv` shows `max|diff| = 0.000000` on all five reported metrics.

## What Is in the Paper (Quick Reference)

The manuscript proposes **STAR** — a *fully distributed* three-stage deployment framework for heterogeneous USV swarms:

| Stage | Mechanism | Source file |
|-------|-----------|-------------|
| 1 | Compressible-fluid self-diffusion (SPH density → pressure) | `src/algorithms/fluid.py` |
| 2 | Local Laguerre (power) partitioning | `src/algorithms/local_laguerre.py` |
| 3 | Vertex-edge virtual forces (VEVF) + hole filling | `src/algorithms/vevf.py`, `hole_fill.py` |

Baselines (all fully distributed): random walk, distributed Lloyd, distributed VFA, distributed lbest PSO — in `src/algorithms/baselines/`.

**Key results (12 seeds, corrected implementation):**
- Benchmark: STAR achieves $0.9707\pm0.0048$ (N=40) and $0.9998\pm0.0003$ (N=100), outperforming all four baselines with **p < 0.001** (paired t-test and Wilcoxon).
- Communication robustness: retains $0.9016$ coverage at a 50% per-link packet-loss rate (and $0.9703$ at 10%).
- Scalability: coverage is $0.630$ at N=20, $0.971$ at N=40, $0.996$ at N=60, $0.999$ at N=80, $0.952$ at N=100, and $0.980/0.991/0.998$ at N=150/200/300.
- Ablation: the Laguerre weighting and VEVF contribute the largest gains ($-0.064$ and $-0.059$ coverage when removed); fluid and hole-fill contribute $-0.007$ and $-0.008$.

**Archival note.** `results/all_runs_v4.csv` retains the pre-correction 12-seed archive verbatim; the old-vs-new comparison is in `results/suite_starfix/old_vs_new_comparison.md`, and the mechanism-fix record is summarized in `paper/Supplementary_Materials.md` (S10). All numbers above, the manuscript, and the shipped CSVs use the corrected implementation.
